# План реализации и проверки

## Порядок работы

1. **Сверить разметку.** Открыть [страницу номинаций](https://slay-award.ru/#nominations)
   в Chrome без расширения. Проверить верхний баннер, блоки после прокрутки,
   мобильное меню и окна, открываемые из карточек. Для каждого подтверждённого
   элемента записать место, адрес или селектор, тип картинки и возможные
   источники для разных ширин экрана. Для кликабельных картинок проверить
   фактический `href` в DOM.
2. **Собрать расширение.** Добавить манифест, локальные файлы замены,
   правила подмены изображений и фильтрацию рекламных ссылок.
   Загрузить `extension/` как распакованное
   расширение и проверить, что оно применяется при первом открытии и
   после обновления страницы.
3. **Закрепить ключевые сценарии.** Добавить небольшой локальный HTML-пример
   и браузерные проверки для изменения разметки и ложных совпадений.
   Повторить ручную проверку после уточнения правил.
4. **Подготовить первую версию.** Зафиксировать версию в манифесте и
   обновить README фактическими шагами установки и известными ограничениями.

## Критерии готовности

| Сценарий | Ожидаемый результат |
| --- | --- |
| Открыть `/#nominations` напрямую, перейти к номинациям из меню, обновить страницу. Повторить с `/?utm_source=test#nominations`. | Якорь открывает нужную секцию. Заставка загрузки и первый экран показывают Swinline. |
| Открыть первый экран на широком и узком экране. Включить режим уменьшенного движения и повторить загрузку. | Выбирается нужный 16-секундный ролик. В обычном режиме видео запускается и повторяется; при уменьшенном движении виден стоп-кадр той же яркости. |
| Проверить заголовок, обычный текст, альтернативные подписи и текст, добавленный после загрузки. | Варианты WINLINE и Winline отображаются как Swinline. |
| Открыть карточку номинации и окно выбора или входа. | Вместо рекламного логотипа отображается локальная версия. Заголовок, список, кнопки, поля и закрытие окна работают. |
| Проверить картинку, в которую логотип встроен как часть изображения. | Отображается подготовленная версия, где видны остальные детали картинки. |
| Добавить картинку Winline после загрузки, затем сменить её источник на обычную картинку. Повторить с `srcset` или `picture`. | Рекламный вариант получает замену, а обычный вариант отображается как задано сайтом. |
| Проверить рекламную картинку, обёрнутую в ссылку на Winline. | На её месте видна розовая версия без перехода по клику и без фокуса по Tab. |
| Сменить `href` обычной ссылки на адрес Winline, а затем обратно. | Рекламная ссылка скрывается. После возврата исходного адреса она снова доступна. |
| Проверить `winline.ru`, `m.winline.ru`, обычную ссылку на Twitch и похожие адреса: `notwinline.ru`, `winline.ru.example.org`, `example.org/?to=winline.ru`. | Скрываются только ссылки на Winline. Похожий текст, внутренние якоря и остальные ссылки остаются доступны. |
| Сравнить обычную и узкую ширину экрана. | Оранжевые акценты становятся розовыми. Другие цвета и расположение элементов сохраняются. |
| Проверить градиенты заголовков, цифры таймера, тени, рамки фокуса и баннер cookie с оригинальными стилями SLAY. | В CSS используются розовые стопы и акценты, включая промежуточные кадры анимаций. |
| Подключить таблицу стилей с правилами для мобильного экрана и воспроизвести отказ CORS. | При успешном чтении порядок каскада сохраняется. При отказе исходная таблица остаётся активной. |
| Проверить фотографию без логотипа и кнопки разных цветов при наведении и фокусе. | Меняются оранжевые детали фото и кнопок. Синие кнопки и нейтральные оттенки сохраняют исходный цвет. |
| Проверить кнопки «Проголосовать» и «Купить билет», заголовок номинаций, стрелки, корону, клоуна и камни вокруг золотого билета. | Красно-оранжевые и тёмные грани этих элементов перекрашиваются в розовые тона. Металл и светлые надписи читаются. |
| Проверить смену подписи «Проголосовать» на «Изменить выбор», новую кнопку в модальном окне и обычный и анимированный варианты кристальной кнопки. | Все варианты компонента `.button-gem` используют розовую графику независимо от текста. |
| Проверить экран загрузки и стрелки карусели, включая стрелки, отрисованные через CSS. | Кристаллы на заставке и в стрелках розовые. |
| Листать карточки «О премии», в том числе с замедленной анимацией. | Обе строки заголовка остаются розовыми до, во время и после перехода. |
| Сравнить портреты победителей с исходными. | Тёмная подсветка за фигурами становится розовой. Основные тона лиц сохраняются. |
| Открыть модальное окно и выпадающее меню. | Оранжевые элементы внутри них становятся розовыми. |
| Открыть отдельный путь на SLAY и другой сайт с таким же HTML в тесте. | Замена оранжевых оттенков применяется на SLAY. Подмена Swinline применяется на главной. Другой сайт отображается в исходных цветах. |
| Отключить расширение и обновить главную. | Страница выглядит как до установки. |

## Как проверять

Для повторяемых проверок использовать Chromium из
[Playwright](https://playwright.dev/docs/chrome-extensions) с отдельным
временным профилем и установленным распакованным расширением. Перехватывать
загрузку тестового URL на уровне браузерного теста и отдавать
локальную тестовую страницу с образцами изображений и ссылок. Такой тест
проверяет настоящий манифест и его ограничения. Для изображений
проверять, что видна именно локальная
замена. Для ссылок проверять видимость, фокус и результат клика.

На живом сайте сравнить главную с включённым и отключённым расширением
в Chrome, затем повторить основные шаги в Edge. Проверять открытие окна
голосования можно без отправки реального голоса. Если вход или какой-либо
этап недоступен, указать это в результатах как непроверенный сценарий.
